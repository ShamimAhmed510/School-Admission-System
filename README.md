# School Admission System 

Complete full-stack School Admission System adhering to all assignment specifications and custom enhancements.

## Features Included:
- **Predefined Class & Shift Dropdowns:** Admins or system selectors pick from standard classes (Class 1 to 10) and shifts (Morning, Day, Evening).
- **Hardcoded Admin Login:** Hardcoded credentials (`admin` / `admin123`) for administrative control.
- **Detailed Admin Dashboard:** View total students per class/shift, student ID / birth registration number, and separation of Confirmed vs Pending (Held) applicants.
- **Enhanced UI Cards:** Displays Student ID, Name, Class & Shift cleanly instead of raw ID clutter.
- **Strict Seat Capacity Validation:** Total applicant holds + confirmed admissions <= total seats. Seat full state blocks applications automatically.
- **Auto-Expiration:** Holds automatically reflect EXPIRED status without page refresh or manual triggers.
